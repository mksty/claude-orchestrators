# Claude orchestrators — installer repo

This repository packages three Claude Code orchestration workflows (`/fable-orchestrator`, `/fable-peer`, `/magnum-opus`) for installation into the user's own `~/.claude/`.

If the user asks you to install, set up, update or remove this, follow [INSTALL.md](INSTALL.md) step by step. If they ask how to use it, explain from [README.md](README.md).

Do not install anything just because this repository was opened; wait for the user to ask.
